## 📄 Papers Worth Reading  

- **[ActionParty: Multi‑Subject Action Binding in Generative Video Games](http://arxiv.org/abs/2604.02330v1)** by Alexander Pondaven *et al.*  
  Introduces **subject state tokens** that let a diffusion world model control up to seven players simultaneously.  
  Enables reliable action‑following and identity preservation, a prerequisite for AI‑driven multiplayer simulations.  
  [PDF](http://arxiv.org/pdf/2604.02330v1.pdf)  

- **[Steerable Visual Representations](http://arxiv.org/abs/2604.02327v1)** by Jona Ruthardt *et al.*  
  Injects textual prompts **inside** a ViT via lightweight cross‑attention, letting the encoder focus on arbitrary objects.  
  Produces zero‑shot visual features that outperform CLIP on anomaly detection and personalized object discrimination.  
  [PDF](http://arxiv.org/pdf/2604.02327v1.pdf)  

- **[Grounded Token Initialization for New Vocabulary in LMs for Generative Recommendation](http://arxiv.org/abs/2604.02324v1)** by Daiwei Chen *et al.*  
  Proposes **GTI**, a pre‑fine‑tuning grounding step that maps novel tokens to semantically meaningful spots in the pretrained embedding space.  
  GTI consistently beats mean‑initialization on industry‑scale recommendation benchmarks, proving that token seeding matters more than data volume.  
  [PDF](http://arxiv.org/pdf/2604.02324v1.pdf)

## 🎓 One Thing to Learn  
**Steerable visual representations** let a vision model shift its attention on‑the‑fly using plain language. Traditional ViTs lock the visual encoder first, then fuse text later; the result is a static feature map that only reacts to the most salient object. By inserting a tiny cross‑attention module **inside** each transformer block, you give the model a “dial” that pulls any concept into focus without retraining the whole network. The payoff is a single backbone that can both retrieve generic image semantics *and* isolate niche items like “red‑capped mushroom” in zero‑shot mode.
