## 📄 Papers Worth Reading
- **[Optimal Linear Regression Without a Variance](https://arxiv.org/abs/2611.27983v1)** by Artin Tajdini, Jasper C. H. Lee, Jonathan Scarlett, Kevin Jamieson — Explores high-probability linear regression in scenarios with finite conditional moments and covariates with finite moments up to a given order. The proposed black-box reduction addresses these challenges, offering insights into robust statistical analysis [PDF](https://arxiv.org/pdf/2611.27983v1.pdf).
- **[A Methodologically Rigorous Benchmark of Linear Regression, RNN, and LSTM for S&P 500 Forecasting](https://arxiv.org/abs/2611.27978v1)** by Hari Sitaula, Joseph Opitz — Presents a comprehensive benchmark of machine learning models for S&P 500 forecasting, emphasizing rigorous methodology in financial forecasting. Findings provide valuable insights for practitioners [PDF](https://arxiv.org/pdf/2611.27978v1.pdf).
- **[MemOnce: A Scalable Memory Architecture for Large Language Models](https://arxiv.org/abs/2611.27973v1)** by Chang Nie, Chaoyou Fu, Songlin Liu, Yiqing Hu et al. — Introduces MemOnce, a novel memory architecture for large language models in long-horizon and continual interactions. By efficiently maintaining reusable memory states, MemOnce addresses challenges posed by existing architectures [PDF](https://arxiv.org/pdf/2611.27973v1.pdf).
