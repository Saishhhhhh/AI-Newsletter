🎓 One Thing to Learn

Server‑side learning adds a lightweight model at the aggregator that learns to predict clean global updates from noisy client submissions. It works by jointly optimizing a server loss on a small synthetic dataset while filtering outliers using a geometric median step. The result is a **dual‑layer defense**: malicious updates are down‑weighted, and the server model continuously adapts to distribution drift. For builders, this means you can launch federated training across untrusted edge devices without redesigning client code or sacrificing accuracy, dramatically reducing the operational cost of secure model scaling.
