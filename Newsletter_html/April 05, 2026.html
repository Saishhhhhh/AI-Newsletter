🎓 One Thing to Learn

**Steerable visual representations** let a vision model shift its attention on‑the‑fly using plain language. Traditional ViTs lock the visual encoder first, then fuse text later; the result is a static feature map that only reacts to the most salient object. By inserting a tiny cross‑attention module **inside** each transformer block, you give the model a “dial” that pulls any concept into focus without retraining the whole network. The payoff is a single backbone that can both retrieve generic image semantics *and* isolate niche items like “red‑capped mushroom” in zero‑shot mode.
